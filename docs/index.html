How it works

One tab, one game, four steps

From a raw disc image to a finished translation, without leaving the application.

01

Load a ROM

Open your disc or cartridge image in the tab for its console and see what game it found.

02

Extract the text

A character table maps raw bytes to readable text — found automatically or marked by hand.

03

Translate

Work through every line with a glossary, a status tracker, and live length warnings.

04

Build the ROM

Pointers are relocated automatically and a finished image or patch is generated.

Features

Everything a translation project needs

A single, focused toolset covering the whole path from raw game data to a translated ROM.

CORE

Character table editor

Map each byte, or sequence of bytes, to the character it represents — including compressed multi-character sequences some games use.

Text extraction

Automatic heuristic scan, or set exact address ranges yourself.

Translation editor

Status tracking, glossary, and length checks as you type.

Pointer relocation

When a translated line changes length, references to it are updated automatically so nothing breaks in-game.

Project management

Save your work, come back later, export or import a project to move it between machines.

ROM or patch output

A complete translated disc image, or a compact IPS patch to share without distributing the original game.

Questions

Good to know

Does RomTranslator include any games?

No. RomTranslator is a translation tool only — it does not provide, host or distribute any commercial game files. You supply your own ROM image.

Do I need to know how to program?

No. Extraction, translation and rebuilding are all handled through the interface. No scripting or hex editing is required for a standard translation project.

Which consoles are supported?

Sega Saturn is the first console module. Support for further consoles will be added over time, each in its own tab.

Can I share a translation without sharing the game?

Yes. RomTranslator can generate an IPS patch file instead of a full ROM, so recipients apply it to their own legally owned copy.

Is it available in my language?

The interface is available in French and English, and automatically follows your Windows display language when supported.
